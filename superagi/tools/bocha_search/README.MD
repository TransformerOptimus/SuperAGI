# SuperAGI BoCha Search Tool

The SuperAGI BoCha Search Tool helps users perform a BoCha search and extract snippets and webpages.

## ⚙️ Installation

### 🛠 **Setting Up of SuperAGI**
Set up the SuperAGI by following the instructions given (https://github.com/TransformerOptimus/SuperAGI/blob/main/README.MD)

If you've put the correct BoCha API key, you'll be able to use the BoCha Search Tool as well.

## Running SuperAGI BoCha Search Tool

You can simply ask your agent about latest information regarding anything in the world and your agent will be able to browse the internet to get that information for you.
